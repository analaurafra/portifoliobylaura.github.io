## 🚀 Cómo Ejecutar Este Portafolio Localmente

Este proyecto está construido con **Jekyll**, un generador de sitios estáticos.

### Requisitos Previos
- Ruby (versión 2.7 o superior)
- Bundler

### Instalación

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/analaurafra/portfoliobylaura.github.io.git
   cd portfoliobylaura.github.io
   ```

2. **Instalar dependencias**
   ```bash
   bundle install
   ```

3. **Ejecutar el servidor local**
   ```bash
   bundle exec jekyll serve
   ```

4. **Abrir en tu navegador**
   ```
   http://localhost:4000
   ```

## 🎨 Personalización

Puedes personalizar este portafolio editando:

- **`_config.yml`**: Configuración general, tema, autor
- **`_layouts/`**: Estructura de las páginas
- **`_sass/`**: Estilos y colores
- **`assets/`**: Imágenes y recursos

Para más información sobre Jekyll, visita [jekyllrb.com](https://jekyllrb.com)
