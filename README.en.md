## 🚀 How to Run This Portfolio Locally

This project is built with **Jekyll**, a static site generator.

### Prerequisites
- Ruby (version 2.7 or higher)
- Bundler

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/analaurafra/portfoliobylaura.github.io.git
   cd portfoliobylaura.github.io
   ```

2. **Install dependencies**
   ```bash
   bundle install
   ```

3. **Run the local server**
   ```bash
   bundle exec jekyll serve
   ```

4. **Open in your browser**
   ```
   http://localhost:4000
   ```
