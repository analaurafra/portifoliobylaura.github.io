## 🚀 Como Rodar Este Portfólio Localmente

Este projeto é construído com **Jekyll**, um gerador de sites estáticos.

### Pré-requisitos
- Ruby (versão 2.7 ou superior)
- Bundler

### Instalação

1. **Clone o repositório**
   ```bash
   git clone https://github.com/analaurafra/portfoliobylaura.github.io.git
   cd portfoliobylaura.github.io
   ```

2. **Instale as dependências**
   ```bash
   bundle install
   ```

3. **Rode o servidor local**
   ```bash
   bundle exec jekyll serve
   ```

4. **Acesse no navegador**
   ```
   http://localhost:4000
   ```
